# Training content review

Reviewed 2026-10-01. The library supports user-created routines; it does not
prescribe personalized programs. Category names indicate exercise emphasis,
not exclusive muscle recruitment. Media are demonstrations, not medical advice.

Removed the old EMG rankings and percentages: several author/URL pairs did not
match, and the values were presented as universal exercise-quality scores.
Removed the composite Scientific Score, which rewarded five sessions weekly
and compared total tonnage across unrelated sessions. Activity counts now have
explicit labels. Previous sets can be repeated without automatically adding
2.5 kg or forcing every user into an 8–12 rep range.

Sources: [ACSM 2026](https://pubmed.ncbi.nlm.nih.gov/41843416/) for general
progressive resistance training; [Refalo et al. 2023](https://pubmed.ncbi.nlm.nih.gov/36334240/)
for the limitations of always training to failure. These are population-level
findings, not guarantees or individualized recommendations. A qualified exercise
professional should review any future prescribed programs before publication.
